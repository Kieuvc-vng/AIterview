Schema Mới — Approach B (Updated)

Thêm description cho JOBS

Database Schema
📋 JOBS (Job Templates)
job_id (PK) ← Unique ID
job_title
level
company
description ← NEW
skills (JSON: ["Python", "SQL", ...])
questions_by_skill (JSON: {Python: [q1, q2, ...], ...})
created_by (HR email)
created_at
👤 CANDIDATES (Ứng viên)
candidate_id (PK)
job_id (FK → JOBS)
name
email
phone
created_at
🎬 INTERVIEWS (Phiên phỏng vấn)
interview_id (PK)
job_id (FK → JOBS)
candidate_id (FK → CANDIDATES)
status (setup / active / completed)
started_at
completed_at
💬 MESSAGES (Tin nhắn)
message_id (PK)
interview_id (FK → INTERVIEWS)
sender (candidate / interviewer)
content
skill_name
question_index
attempt_number
created_at
📝 SUMMARIES (Tóm tắt)
summary_id (PK)
interview_id (FK → INTERVIEWS)
skill_name
question_index
question_text
main_answer_summary (tóm tắt câu chính)
followup_summary (tóm tắt follow-up)
created_at

Ví dụ JOBS record:

{job_id: "JOB-001", job_title: "Data Engineer", level: "Mid", company: "TechCorp",
description: "Xây dựng data pipeline, ETL, quản lý data warehouse", ...}
