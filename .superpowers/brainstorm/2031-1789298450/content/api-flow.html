API Flow — 3 Phase chính

Setup → Interview → Review

Phase 1️⃣: SETUP (Tạo Job Library)

Luồng:

  1. HR upload JD → API parse job info (job_title, level, company)
  2. API suggest skills → HR chọn
  3. API generate questions per skill → HR review/edit
  4. HR click "Save to Library" → tạo JOBS record
  5. ✅ Job template được lưu, reusable cho nhiều ứng viên

Endpoints:

  • POST /setup/parse-jd → extract job info
  • POST /setup/suggest-skills → suggest từ JD
  • POST /setup/generate-questions → generate từ skills
  • POST /jobs ← NEW → save job to library

Phase 2️⃣: SEND TO CANDIDATE (Tạo Link Phỏng Vấn)

Luồng:

  1. HR click job từ library
  2. Form xuất hiện: nhập Tên, Email, Phone ứng viên
  3. HR click "Generate Link" → tạo CANDIDATE + INTERVIEW record
  4. ✅ Unique link được tạo (browser token, 1 device)
  5. HR send link → ứng viên click → phỏng vấn start

Endpoints:

  • GET /jobs ← NEW → list jobs từ library
  • GET /jobs/:job_id ← NEW → xem detail job
  • POST /candidates ← NEW → tạo candidate
  • POST /interviews ← NEW → tạo interview session

Phase 3️⃣: INTERVIEW (Phỏng Vấn)

Luồng:

  1. Ứng viên trả lời Q1 → API evaluate (AI: good or not)
  2. Nếu cần → AI hỏi follow-up → ứng viên trả lời
  3. Sau mỗi câu → AI TÓM TẮT (NEW) → lưu vào SUMMARIES
  4. Loop cho hết questions
  5. Interview end → ứng viên chuyển qua review page

Endpoints:

  • GET /interviews/:interview_id → xem session
  • POST /interviews/:interview_id/start → start interview
  • POST /interviews/:interview_id/message → gửi tin nhắn
  • POST /summaries ← NEW → lưu tóm tắt

Phase 4️⃣: REVIEW (Xem Kết Quả)

Luồng:

  1. HR xem job → list candidates từ library
  2. HR click 1 candidate → thấy tóm tắt (layout: hybrid)
  3. Mặc định xem tóm tắt, click "expand" xem full chat
  4. HR export PDF/CSV

Endpoints:

  • GET /jobs/:job_id/candidates ← NEW → list candidates per job
  • GET /summaries/:interview_id ← NEW → xem tóm tắt
  • POST /export/pdf → export (cần update)
  • POST /export/csv → export (cần update)

⚠️ Thay đổi chính:

  • ❌ LOẠI: rubricGenerator (không chấm điểm nữa)
  • ✅ THÊM: summaryGenerator (tóm tắt câu trả lời)
  • ✅ THÊM: jobLibrary APIs (CRUD jobs)
  • ✅ THÊM: candidateManagement APIs (CRUD candidates)
